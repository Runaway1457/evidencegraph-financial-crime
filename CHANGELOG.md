## [0.2.0] - 2026-09-14

### Added

- Evidence-first financial-crime domain with case-local provenance invariants
- SQLAlchemy/PostgreSQL aggregate persistence and Alembic migration checks
- Composite relational constraints for graph and citation integrity
- SHA-256-linked audit and chain-of-custody records
- Governed deterministic investigator and fail-closed grounding gate
- OPA authorization adapter, Rego policy and policy tests
- Transactional outbox with leasing, retry, idempotency and dead-letter state
- Advanced React/TypeScript investigation workbench
- Multi-stage non-root containers and verified full-stack Compose smoke test
- Adversarial grounding evaluation dataset and reproducible report
- Architecture decisions, threat model, model card, data card and runbook
- Flagship portfolio README and launch kit
